# Novenetech Campus MVP

MVP Next.js/TypeScript de la plateforme Novenetech Campus.

## Démarrage
1. `npm install`
2. `npm run dev`
3. Ouvrir http://localhost:3000

## Pages
- `/` landing page
- `/programme` programme
- `/login` connexion MVP
- `/dashboard` espace étudiant
- `/crm` CRM de prospection
- `/admin` back-office MVP

## Prochaine intégration
Supabase Auth + PostgreSQL, paiement local, persistance progression/CRM, contenus des 28 jours, automatisations WhatsApp et attestations.
